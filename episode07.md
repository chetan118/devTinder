- Differnce between JS object and JSON?

  - The key differences between a JavaScript object and JSON (JavaScript Object Notation) are as follows:
  - Purpose:

    - JavaScript Object: A JavaScript object is a data structure used within a JavaScript program to store and organize data as key-value pairs, often including methods (functions). It's an in-memory representation for programmatic manipulation.
    - JSON: JSON is a lightweight, text-based data interchange format. Its primary purpose is to transmit data between systems (e.g., client-server communication) or to store structured data in a human-readable and machine-parseable format.

  - Syntax and Structure:

    - JavaScript Object: Keys in JavaScript objects can be unquoted if they are valid JavaScript identifiers (e.g., myKey: 'value'). Values can be various JavaScript data types, including functions, undefined, and Date objects.
    - JSON: All keys in JSON must be strings enclosed in double quotes (e.g., "myKey": "value"). JSON only supports a limited set of data types: strings, numbers, booleans, arrays, objects, and null. It cannot contain functions or other JavaScript-specific constructs.

  - Usage:

    - JavaScript Object: Used for creating and working with structured data during the execution of a JavaScript program. [1]
    - JSON: Used for data serialization (converting a JavaScript object into a string for storage or transmission) and deserialization (converting a JSON string back into a JavaScript object). It is language-agnostic, meaning it can be easily parsed and generated by various programming languages, not just JavaScript.

  - Nature:

    - JavaScript Object: An actual object within the JavaScript runtime environment.
    - JSON: A string representation of data that looks like a JavaScript object literal but is fundamentally a text format. It is not an object itself until parsed.
